# Bot base para discord.js

El proyecto está programado en JavaScript usando la librería discord.js con Node.js

## Dependencias
- instalar dotenv
    
```powershell
npm install dotenv
```
- instalar discord.js
```powershell
npm install discord.js
```

Crear un archivo .env con el siguiente contenido:
```env
DISCORD_TOKEN = obtenido desde discord dev portal -> bot
CLIENT_ID = obtenido desde discord dev portal -> general 
GUILD_ID = obtenido desde clic derecho al servidor de prueba (opciones de desarrollador requeridas)
```
